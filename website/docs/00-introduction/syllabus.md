# Course Syllabus: Physical AI & Humanoid Robotics

## Course Overview

This comprehensive course provides an in-depth exploration of Physical AI and Humanoid Robotics, bridging the gap between digital intelligence and embodied physical systems. The course combines theoretical foundations with hands-on implementation using state-of-the-art tools and platforms.

### Course Duration
- **Total Duration**: 12 weeks (3 months)
- **Weekly Commitment**: 10-15 hours per week
- **Format**: Self-paced with recommended milestones
- **Prerequisites**: Basic programming knowledge (Python/C++), Linear Algebra, Calculus

### Course Objectives

By the end of this course, students will:

1. **Understand Physical AI Principles**: Grasp the fundamental concepts connecting artificial intelligence with physical systems
2. **Master ROS 2 Architecture**: Implement complex robotic systems using ROS 2 communication patterns and tools
3. **Design Robot Models**: Create detailed robot descriptions using URDF and XACRO
4. **Simulate and Test**: Deploy and test robotic behaviors in realistic simulation environments
5. **Implement Perception Systems**: Integrate sensors and computer vision for environmental understanding
6. **Develop Locomotion Algorithms**: Create bipedal planning and balance algorithms for humanoid robots
7. **Integrate Vision-Language-Action**: Implement conversational AI that can execute physical tasks
8. **Complete Capstone Project**: Demonstrate proficiency by building a functional humanoid robotics prototype

## Weekly Schedule

### Week 1-2: Introduction & Foundations
- **Topics Covered**:
  - What is Physical AI?
  - Embodied Intelligence concepts
  - Course structure and setup
  - Hardware requirements and options
- **Assignments**:
  - Environment setup
  - Course platform familiarization
  - Basic ROS 2 concepts quiz

### Week 3-4: ROS 2 Nervous System
- **Topics Covered**:
  - ROS 2 architecture and DDS
  - Nodes, topics, services, and actions
  - Parameter management
  - Launch systems
- **Assignments**:
  - Implement first ROS 2 nodes
  - Create publisher-subscriber patterns
  - Design service-based communication

### Week 5-6: Robot Description
- **Topics Covered**:
  - URDF (Unified Robot Description Format)
  - XACRO for parameterized models
  - Gazebo integration
- **Assignments**:
  - Create simple robot model
  - Add joints, links, and materials
  - Import and modify existing models

### Week 7-8: Simulation
- **Topics Covered**:
  - Gazebo Classic and Ignition Harmonic
  - Isaac Sim for NVIDIA platforms
  - Physics engines and simulation parameters
- **Assignments**:
  - Configure simulation environments
  - Implement physics-based interactions
  - Test robot models in simulation

### Week 9-10: Perception
- **Topics Covered**:
  - Sensor integration (LIDAR, cameras, IMU)
  - Isaac ROS perception stack
  - 3D vision fusion
- **Assignments**:
  - Sensor data processing
  - Point cloud operations
  - Object detection and tracking

### Week 11-12: Navigation & Locomotion
- **Topics Covered**:
  - Navigation 2 (Nav2) stack
  - Bipedal planning algorithms
  - Balance and recovery systems
- **Assignments**:
  - Path planning implementation
  - Balance control algorithms
  - Capstone project milestone completion

## Assessment Structure

### Practical Projects (70%)
- **Weekly Assignments**: 30%
- **Mid-term Project**: 15%
- **Capstone Project**: 25%

### Theory & Quizzes (30%)
- **Weekly Quizzes**: 15%
- **Final Exam**: 15%

## Required Resources

### Software
- Ubuntu 22.04 LTS (or ROS 2 Humble compatible system)
- ROS 2 Humble Hawksbill
- Gazebo Garden or Isaac Sim
- Git version control
- Visual Studio Code or preferred IDE

### Hardware (Optional but Recommended)
- Development computer with NVIDIA GPU (for Isaac Sim)
- 3D camera (Intel RealSense D435i recommended)
- Access to humanoid robot platform (simulation alternatives provided)
