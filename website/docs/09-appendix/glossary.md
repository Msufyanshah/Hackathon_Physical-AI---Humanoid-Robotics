# Glossary of Terms

This glossary provides definitions for key terms used throughout the Physical AI & Humanoid Robotics course. Understanding these terms is essential for mastering the concepts and implementing practical systems.

## A

**Actuator**: A mechanical device that converts energy (usually electrical) into physical motion. In humanoid robots, actuators control joint movements.

**Affordance**: The property of an object that defines how it can be interacted with. For example, a handle affords grasping.

**Artificial Intelligence (AI)**: The simulation of human intelligence processes by machines, especially computer systems, including learning, reasoning, and self-correction.

**Autonomous**: Operating independently without human intervention.

## B

**Bipedal**: Having two legs for walking, as opposed to quadrupedal (four legs) or wheeled locomotion.

**Bounding Box**: A rectangular box that encloses an object in an image, typically defined by its (x, y) coordinates and width/height.

**Bridge (LLM-ROS Bridge)**: A system component that translates natural language commands from large language models into ROS messages and services.

## C

**Captioning**: Generating natural language descriptions of visual scenes or images.

**CLIP (Contrastive Language-Image Pretraining)**: A neural network trained to associate text and images using contrastive learning.

**Cogeneration**: The simultaneous production of electrical and thermal energy from a single energy source, though in robotics it may refer to simultaneous processing of multiple modalities.

**Computer Vision**: A field of artificial intelligence that trains computers to interpret and understand the visual world.

**Conversational AI**: Artificial intelligence systems designed to engage in human-like conversations.

**Convolutional Neural Network (CNN)**: A class of deep neural networks, most commonly applied to analyzing visual imagery.

## D

**Deep Learning**: A subset of machine learning based on artificial neural networks with representation learning.

**Detection**: Identifying and locating objects within an image or video feed.

**Distributed System**: A system whose components are located on different networked computers, which communicate and coordinate their actions by passing messages to one another.

**Domain Randomization**: A technique for training machine learning models on simulated data by randomizing various aspects of the simulation to improve transfer to the real world.

## E

**Embodied AI**: Artificial intelligence systems that interact with the physical world through a body or robot.

**Encoder**: A component in neural networks that transforms input into a compressed representation.

**Episodic Memory**: A type of long-term memory that records personal experiences and events in a sequential/chronological manner.

**Embodiment**: The concept that intelligence is shaped by the physical form of an agent and its interactions with the environment.

## F

**Fine-tuning**: The process of taking a pre-trained model and adjusting it to a specific task or dataset.

**Foundation Model**: Large-scale models trained on broad data that can be adapted to various downstream tasks.

**Forward Kinematics**: Calculating the position of the end effector (robot hand) based on joint angles.

## G

**Generative AI**: AI systems that can generate new content such as text, images, or sounds.

**GPT (Generative Pre-trained Transformer)**: A class of language models that use the transformer architecture.

**GPU (Graphics Processing Unit)**: A specialized electronic circuit designed to rapidly manipulate and alter memory to accelerate the creation of images in a frame buffer intended for output to a display device, commonly used for neural network training.

**Grasping**: The process of securely holding an object using robot end effectors.

## H

**Hardware-in-the-Loop (HIL)**: A testing technique that uses actual hardware components within a simulation environment.

**HRI (Human-Robot Interaction)**: The field studying interactions between humans and robots.

**Humanoid Robot**: A robot with a physical body resembling that of a human, typically having a torso, two arms, and two legs.

## I

**Inference**: The process of using a trained model to make predictions on new data.

**Inverse Kinematics**: Calculating joint angles required to place the end effector at a desired position and orientation.

**Isaac ROS**: NVIDIA's collection of hardware-accelerated perception and navigation packages optimized for ROS 2.

**Isaac Sim**: NVIDIA's robotics simulation application based on NVIDIA Omniverse.

## K

**Kinematics**: The study of motion without considering the forces that cause the motion.

**Knowledge Graph**: A knowledge base that uses a graph-structured data model to represent and store knowledge.

## L

**Large Language Model (LLM)**: A language model based on transformer architecture with many parameters (typically billions) that has been trained on diverse internet text.

**Locomotion**: The ability to move from one place to another.

**LLM (Large Language Model)**: See Large Language Model.

**Language Understanding**: The ability of a system to interpret and comprehend natural language commands.

**Learning Rate**: A hyperparameter that controls how much to change the model in response to the estimated error each time the model weights are updated.

## M

**Manipulation**: The use of a robot's end effector to interact with objects in the environment.

**Mask R-CNN**: A deep neural network for instance segmentation, which identifies objects and their pixel-wise boundaries.

**Mechatronics**: An interdisciplinary branch of engineering that combines mechanical, electrical, computer, telecommunications, systems, control, and product engineering.

**Middleware**: Software that acts as a bridge between operating systems and applications, particularly important in robotics for communication between components.

**Model Predictive Control (MPC)**: An advanced method of process control that uses a model of the system to predict future behavior.

## N

**Natural Language Processing (NLP)**: A field of AI focused on the interaction between computers and humans through natural language.

**Navigation**: The process of planning and executing motion to reach a goal location.

**Neural Network**: A series of algorithms that endeavors to recognize underlying relationships in a set of data through a process that mimics how the human brain operates.

**Node (ROS)**: A process that performs computation in the ROS system.

**Nueral Radiance Fields (NeRF)**: A method for synthesizing novel views of complex 3D scenes based on a sparse set of input images.

## O

**Object Detection**: The computer vision technology that identifies and locates objects within an image or video.

**Ontology**: A formal naming and definition of the types, properties, and interrelationships of the entities for a particular domain.

**OpenAI**: An artificial intelligence company that conducts research in, develops, and applies AI technology.

**Omnidirectional**: Capable of movement in any direction.

## P

**Path Planning**: The computational process of determining a route from a start to a goal location.

**Perception**: The process of acquiring, interpreting, selecting, and organizing sensory information.

**Physical AI**: The field of artificial intelligence focused on understanding and developing agents that interact with the physical world.

**Point Cloud**: A set of data points in space, typically defining the external surface of an object or environment.

**Prompt Engineering**: The practice of designing and refining inputs to elicit desired responses from large language models.

**PID Controller (Proportional-Integral-Derivative)**: A control loop mechanism widely used in industrial control systems.

## Q

**Quaternion**: A mathematical notation for representing orientations and rotations in 3D space, often used in robotics for specifying robot poses.

## R

**Robot Operating System (ROS)**: Flexible framework for writing robot software that provides services designed for a heterogeneous computer cluster.

**ROS 2**: The second generation of the Robot Operating System.

**Reinforcement Learning**: A type of machine learning where an agent learns to behave by performing actions and receiving rewards or penalties.

**RGB-D**: Color image data (Red, Green, Blue) with the addition of depth information (D).

**Reactive System**: A system that automatically adjusts its behavior based on environmental changes.

**RRT (Rapidly-exploring Random Tree)**: A path planning algorithm that builds a space-filling tree by randomly expanding from initial configuration.

## S

**SLAM (Simultaneous Localization and Mapping)**: The computational problem of constructing or updating a map of an unknown environment while simultaneously keeping track of an agent's location within it.

**SDF (Simulation Description Format)**: An XML-based format for describing robots and environments in simulation.

**Service (ROS)**: A synchronous communication pattern in ROS where one node sends a request to another and waits for a response.

**Simulation**: The creation of a model of a real system to understand its behavior and performance.

**Spatial Reasoning**: The cognitive process of understanding the spatial relationships between objects.

**System of Systems**: A collection of task-oriented or dedicated systems that pool their resources and capabilities together to create a new, more complex system.

## T

**Transformer**: A deep learning model architecture that uses attention mechanisms to weigh the importance of input data.

**Teleoperation**: The remote operation of a robot by a human operator.

**Thompson Sampling**: A heuristic for choosing actions that addresses the exploration-exploitation dilemma in decision-making.

**Trajectory**: A path with timing information, specifying where the robot should be at each point in time.

**Tactile Sensors**: Sensors that detect touch, pressure, or other haptic information.

## U

**URDF (Unified Robot Description Format)**: An XML format for representing a robot model, widely used in ROS.

**Uncanny Valley**: A hypothesis in the field of human aesthetics which holds that when human replicas appear almost, but not exactly, like real human beings, it causes a response of unease or revulsion among human observers.

**Unstructured Environment**: An environment that lacks predetermined organization, layout, or characteristics.

## V

**VLA (Vision-Language-Action)**: An integrated system combining visual perception, language understanding, and physical action.

**Vision System**: The components and algorithms responsible for processing visual information from cameras and other optical sensors.

**Vector Database**: A type of database that stores and retrieves vector embeddings, particularly useful for semantic search in AI applications.

**VQA (Visual Question Answering)**: The task of answering questions about visual content.

## W

**Waypoint**: A set of coordinates that define a point in physical space, used for navigation and path planning.

**Wheelchair Robotics**: Robots designed specifically to assist users of wheelchairs.

**Whole-body Control**: Control strategies that consider the entire body of a robot when planning motions and forces.

## X

**Xacro**: An XML macro language that allows definitions of shorter, more intuitive XML segments for URDF files.

## Y

**Yaw**: The rotation around the vertical (up-down) axis of a robot or vehicle.

## Z

**Zero-shot Learning**: A machine learning setting where a model learns to recognize new classes without having seen any training examples from those classes.

**ZMP (Zero Moment Point)**: A criterion used in robotics and biomechanics to study and measure the stability of legged robots and humans during walking.
